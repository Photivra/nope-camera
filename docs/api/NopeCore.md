## `CameraModel`

public, declared in `Sources/NopeCore/CameraModel.swift`

```swift
@MainActor final class CameraModel
```

The camera's state machine: the single object an interface talks to.

An interface observes ``state`` and sends ``CameraIntent`` values through ``send(_:)``.
The model asks its ``CaptureBackend`` for facts and decides the next state; the interface
holds no rules of its own (AGENTS.md, "One direction of flow").

The model is isolated to the main actor, so an interface can read ``state`` directly.

## `SimulatedCaptureBackend`

public, declared in `Sources/NopeCore/SimulatedCaptureBackend.swift`

```swift
struct SimulatedCaptureBackend
```

A ``CaptureBackend`` that returns fixed answers instead of talking to hardware.

Use it in tests, SwiftUI previews and UI tests, and in development builds until the
AVFoundation adapter is wired in. It never shows a system prompt.

```swift
let backend = SimulatedCaptureBackend(
    permission: .notDetermined,
    permissionAfterRequest: .authorized,
    capabilities: DeviceCapabilities(lenses: [Lens(id: "wide", kind: .wide, supportsBayerRAW: true)])
)
let model = CameraModel(backend: backend)
```
