## `CameraPermission/init(_:)`

public, declared in `Sources/NopeCapture/CameraPermission+AVFoundation.swift`

```swift
init(_ status: AVAuthorizationStatus)
```

Converts an AVFoundation authorization status to a `NopeCore` permission.

A status added in a future iOS release is treated as `CameraPermission.restricted`:
nope. must not assume access it can't confirm, and it must not ask again for a state it
doesn't understand.

- Parameter status: The value from
  [`AVCaptureDevice.authorizationStatus(for:)`](https://developer.apple.com/documentation/avfoundation/avcapturedevice/authorizationstatus(for:)).

## `SystemCameraAuthorization`

public, declared in `Sources/NopeCapture/SystemCameraAuthorization.swift`

```swift
struct SystemCameraAuthorization
```

Reads and requests camera permission from the system.

This is a hardware adapter: requesting access shows a system prompt that a unit test can't
answer, so the file is listed in `scripts/coverage-exclusions.txt` and verified on a device.
Its status conversion lives in `CameraPermission+AVFoundation.swift`, which is fully tested.
