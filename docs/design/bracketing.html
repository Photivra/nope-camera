Bracketing

Design version: 1.0.0, direction B · Reach. Bracketing proposed 2026-11-18: the menu and exposure bracketing for release 1.0.0, focus bracketing for release 1.1.0. It becomes part of the plan when the decisions in BRACKETING.md are made.

Bracketing becomes a word on the drive strip, with a card that says what one press takes and a sheet, Bracket Settings, that holds every option. Release 1.0.0 ships that menu with the exposure bracketing the app already has. Focus bracketing, a series at stepped focus positions for stacking in other software, is designed here and built in release 1.1.0: it appears as a second type in the same sheet, on the same card, with nothing moved. The app never stacks or merges the bracket’s frames; each frame is one single-frame Bayer RAW photo saved on its own, with the same metadata allowlist, read-back and signing as any photo. The build specification, the strings and the owner’s decisions are in BRACKETING.md.

  • Photo first. A bracket is one tap from the default screen, and what the next press takes is always written on the picture’s lower edge.
  • One home. The Bracketing section leaves Pro Tools, as Interval did.
  • Honest to the phone. Focus is shown as a position on the lens’s own scale, because iPhone reports no focus distance. No time or rate is promised.
  • Nothing shown before it exists. In 1.0.0 the sheet has no Type row; 1.1.0 adds it above the rows already there.

What the iPhone can do

FactEvidenceWhat follows
An exposure bracket is one request to the camera, with each frame’s shutter speed and ISO set exactlyIn the code today, and Apple’s documentationFrames are delivered in the order asked for, so Order needs no new capture path. The request can’t be cancelled once sent, so there is no Stop while the frames are taken.
The most frames in one bracket depends on the lens and formatApple’s documentation; read at run time todayFrames offers only the counts the lens reports.
Brackets never fire the flashApple’s documentation; in the code todayStated on the sheet.
Focus can be set to a position from 0 to 1 on lenses that support it, and the camera reports when the lens is thereApple’s documentation (iOS 27.2 SDK)The position “does not correspond to an exact physical distance”, differs from device to device, and 1 is not infinity. So the design uses positions, never distances.
The phone reports the minimum focus distance of a lens, in millimeters, or that it is unknownApple’s documentationThe only distance available. No focus distance for a position, and no calibration quality, exists in the iOS 27.2 SDK.
There is no system focus bracketApple’s documentationA focus bracket is separate photos: move the focus, wait, take one photo, save it. So it can be stopped between frames.
How long a focus move and a RAW photo take, and whether the lens reaches each positionNot measuredNo time is promised. The card shows the frame count only. To be measured on each lens (BRACKETING.md, section 9).
Whether even steps on the lens’s scale give even steps in sharpness, and how much the picture’s edges shift with focusNot measuredAssumptions until checked on a device. No wording depends on them.

Buttons, assistive technology, Apple Watch, Siri

InputWhat happens
Shutter, volume buttons, Camera Control, SpaceTakes the bracket (after the start delay). While a delay counts down, cancels it. While a focus bracket runs, stops it after the current frame. Holding does nothing more than a press.
VoiceOverTake Photo, button; value “Bracket, exposure, 3 frames”. The card is the button Bracket Settings. Progress and the result are announced. Nearest and Farthest are buttons with their values; the focus slider is adjustable.
Voice Control and Switch ControlEvery control has a visible name: Bracket, Bracket Settings, Frames, Step, Order, Start Delay, Cancel, Stop Bracket, Nearest Focus, Farthest Focus, Set Nearest Focus, Use the Whole Range. Nothing needs a hold or a drag.
Apple WatchTake Photo on the watch takes what the phone’s strip says, so with Bracket selected it takes the bracket, and the watch says “Photos saved and signed” or “Photos saved, not all signed”, as today. During a focus bracket the watch says the camera was busy. No watch screen changes.
Siri and Shortcuts1.0.0: Take Bracket as today (Frames, Step, Delay, Lens), plus Order. 1.1.0: a Type parameter (Exposure, Focus); with Focus, Frames and Range (As Set in nope., Whole Range).
Live ActivityNone for an exposure bracket, which lasts about as long as its exposures. A focus bracket shows “Frame 4 of 12”, as an Astro run does (1.1.0).

What stays as it is

  • Each frame: one single-frame Bayer RAW photo, saved as its own photo, with the allowlist, the read-back and signing when it is on. Nothing is merged, aligned or stacked.
  • No flash in a bracket. Storage and battery checks. The session’s photos in the Last Photo viewer, where each frame is a page.
  • Presets keep holding the bracket. The Apple Watch screens.
