Privacy
Exact model for RAW editors

Exact model for RAW editors

Saves the exact iPhone model in the RAW file, so editors like desktop RAW apps can pick their color profile for this camera.

If you turn it off: nope. writes a generic name instead, because the RAW format requires one. Editors then use the color data saved in the file, so colors stay correct but may differ slightly from the editor's own profile.

Millions of phones share this model, so it doesn't identify you.
