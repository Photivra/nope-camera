Manual controls

Off by default; turn it on in Settings → Manual controls. Every control follows the same structure: the same slot, the same layout, the same gestures.

Fixed gridSix slots in the same order on every device: EV, ISO, Shutter, Aperture, Focus, WB. A control the device can't set stays in its slot, marked "Fixed" or "n/a", so nothing jumps around.
One panel patternTap a slot to open its panel: the name, an Auto/Manual control, a large value, a ruler with real units, the range for this lens, and Reset.
One tap to full auto"All Auto" appears whenever any control is set manually and returns every control to the meter at once. Turning manual controls off in Settings does the same.
Honest stateA green M means you set it; a gray A means the meter sets it. The meter at the top shows exposure against the meter's reading. Values use real units (ISO, seconds, f-number, kelvin); focus is a relative Near–Far scale, because iOS reports no distance.
Everything the device allowsIn RAW mode, nope. exposes every exposure and focus control the camera hardware supports: P, S, ISO priority and M modes, spot/center/matrix metering, AE and AF lock, bracketing, interval shooting, and pro exposure tools. Nothing processes the photo; multi-frame tools save separate RAWs.
AccessibleEach slot is a VoiceOver adjustable element (swipe up or down). At accessibility text sizes, the panel becomes a full-screen list with steppers.
