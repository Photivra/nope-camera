Design system

Design version: 1.0.0, direction B · Reach (2026-11-17). Planned design for release 1.0.0; the app is built to match it. Includes the Settings structure and the device coverage accepted on 2026-11-17 (SETTINGS-PLAN.md), and the Last Photo viewer decided on 2026-11-18.

The tokens of direction B. Each name maps one to one to a Swift constant in a new file, Sources/NopeUI/DesignTokens.swift; the same list, in a form for the build, is in tokens.md. Every literal spacing, radius, size and color in the app, the widgets, the Live Activity and the watch app is replaced by one of these.

Color

The camera is always dark. One meaning for each color: teal for verified facts, amber for warnings, white fill for the selected item. No yellow. Teal and amber are the system colors, so iOS adapts them for Increase Contrast; the hex values here are their standard dark values, for the mockups. Brand color reaches system controls only through tint.

Text needs 4.5:1 and symbols and control outlines 3:1 (WCAG 2.2 AA). Pure red on black is 5.3:1, and black on pure red is 5.3:1. Settings, Presets, first run and the permission states follow the system appearance, where secondary text is #6D6D72 in light (4.9:1 on the grouped background).

App icon: the color of the period

The icon keeps the “n.” in the photo frame. The decision is the color of the period. See icon.html: the recommendation is to keep it teal, the one accent the app uses for verified facts.
