Monochrome copies (issue 188)

The request is to capture only monochrome data, without removing color afterwards. The design says what is possible and what is not. Built only if the research step is a go and the owner chooses it (plan, R17 and decision 60).

  • Nothing here changes a RAW file. With RAW only and no copy, Monochrome has nothing to apply to, and the page says so.
  • With Night Mode and Red Viewfinder on, the live picture stays red.
  • The copy is signed, checked and listed like any other copy.

Proposed 2026-11-28 for release 1.1.0. A sketch of layout, states and wording, not a pixel-exact screen. The specification is in release-1.1.md; the plan is in docs/plans/1.1.0.md. Wording is a draft until the Honesty review.
