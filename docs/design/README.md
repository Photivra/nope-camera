# Design

The design of Photivra Nope Camera for release 1.0.0, in direction B (Reach), chosen from the options of issue 74. Static HTML mockups with a PNG of each screen, plus the specifications the app is built from. Open [overview.html](overview.html) in a browser to start; nothing here is part of the app build.

**Design version: 1.0.0 (2026-11-17; the Last Photo viewer, the Photo Details redesign, Burst and bracketing added 2026-11-18), planned.** This set is ahead of the app: release 1.0.0 is built to match it. Labels and behavior come from the code as of 0.3.0, except where a change is stated. Sample values (file sizes, lens ranges, timings) are examples. 353 screens are drawn (205 for iPhone, 84 for iPad, 33 for the iPhone Duo, 31 for Apple Watch), 44 of them for bracketing, 19 of those for focus bracketing in 1.1.0; the PNG files total 14.1 MB. A screen is drawn for a device where its layout, presentation or reach differs from the iPhone drawing; [layouts.html](layouts.html) states the rule for the rest.

## Rules for this folder

- Only the current design is kept here. When a release changes the UI, update these files in the same release and set the version line above. Older versions stay in git history.
- Colors: teal only for verified facts, amber only for warnings (always with a symbol and words), filled white for the selected item, and no yellow. Night mode is the app's pure red on black.
- The files are self-contained: inline CSS and SVG, with no scripts, fonts or other external requests. The site figures (`screens/site-*`) embed a Latin subset of Inter, because site artwork may not use an Apple system font. Gallery pages show the PNG files from `screens/`. Placeholder pictures are drawn in SVG; there are no photos or device captures.
- Until 1.0.0 is released, this set is the plan and the app follows it. After that, when a mockup and the app disagree, the app is right; fix the mockup.
