# Source files excluded from the 100% coverage gate, one path per line.
# Only hardware adapters that can't run in a unit test belong here. Each one is a thin wrapper
# behind a NopeCore protocol, its logic is moved into tested files, and it is verified on a
# device before release (AGENTS.md, "Full test coverage"). Adding a line is a reviewed decision.

# Requesting camera access shows a system prompt a unit test can't answer.
Sources/NopeCapture/SystemCameraAuthorization.swift
# The AVFoundation session, camera input and photo output need camera hardware; the Simulator
# has none. Its decisions are in LensCatalog, CapturePolicy, PhotoSettingsFactory and
# CaptureReadiness, which are fully tested.
Sources/NopeCapture/SystemCaptureHardware.swift
# The rotation coordinator needs a camera device; the Simulator has none. The layer hookup is in
# CaptureSessionPreviewSource, which is fully tested.
Sources/NopeCapture/PreviewRotation.swift
# The Secure Enclave doesn't exist in the iOS Simulator.
Sources/NopeSigning/SecureEnclaveSigningKey.swift
# Adding to the photo library shows the add-only Photos prompt and changes the person's library;
# a unit test can do neither. Its decisions are in PhotoKitMapping, which is fully tested.
Sources/NopeCapture/PhotoKitLibrary.swift
# Core Image's RAW filter needs a real Bayer DNG, which can't be built in a unit test (ImageIO
# and Core Image don't decode a hand-built DNG). RAWDeveloper and PhotoEncoder are fully tested
# with a fake renderer.
Sources/NopeDevelop/CoreImageRAWRenderer.swift
