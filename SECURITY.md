# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting: on the **Security** tab, choose **Report a vulnerability**. Do not open a public issue.

Include the affected version, the device and OS version, steps to reproduce, and the impact. You will receive an acknowledgment, and a fix or response is coordinated before any public disclosure.

## Scope

In scope:
- the app's source code in this repository;
- any way the app or its saved files could:
  - make a network connection;
  - expose private metadata;
  - link photos to each other or to a device;
  - produce a signature that validates for a modified photo.

Out of scope:
- behavior of the operating system, the Photos app or cloud services, which are outside the app's control (see the app's Honesty screen);
- third-party forks.

## Supported versions

Security fixes go into the latest released version. There is no release yet.
